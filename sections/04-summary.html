Frameworks like the W3C PROV data model formalize these relationships by linking Entities (data artifacts), Activities (processing steps), and Agents (systems or users), while workflow provenance tools capture the exact execution environments of machine learning pipelines. Depending on the application, provenance can be tracked at varying levels of granularity—ranging from coarse-grained dataset lineage to fine-grained row- and cell-level tracking—revealing not just which features drove an AI decision, but why those features took those values in the first place.
